# Design round one (rejected)

Ten skins of one layout, built 2026-09-05 as Claude Design canvases. Rejected in full: every board shared the same skeleton (header, image left, text and CTA right, thumbnail row) and several hit known AI-design tells (cream + terracotta, black + acid green, broadsheet hairlines, ALL-CAPS eyebrows, middle-dot metadata).

Kept as a record. `src/*.dc.html` are the artboards; `build.ts` injects real knots from `../src/knot.ts` in place of `<!--KNOT-X-->` markers. The seeded canvas files are gitignored.
